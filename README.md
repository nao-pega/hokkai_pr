# hokkai_pr
##  北海道魅力発見!! 

## 概要
このプロジェクトは、日本最北の地である北海道の観光情報を集約し、そのグルメ、絶景スポット、文化・イベントの魅力を国内外に発信する静的Webサイトです。
北の空と海をイメージした深い青を基調とし、訪問者が北海道への旅に魅力を感じるような情報提供を目指しています。

## 主なコンテンツ・機能サイトは以下の主要な4ページで構成されています。
1.HOME。北海道の魅力を映し出すメインページです。スライドショー機能と、札幌雪まつり、YOSAKOIソーラン祭り、ライラックまつりなどの主要イベントの紹介を掲載しています。

2.グルメ・特産品。北海道を代表する食文化を紹介するページです。札幌味噌ラーメン、新鮮なカニ・海鮮丼、ジンギスカン、銘菓（白い恋人など）、酪農製品（ソフトクリーム）といった名物を写真付きで解説しています。

3.絶景スポット。北海道各地の息をのむような美しい景色を特集したページです。美瑛の青い池、富良野のラベンダー畑、摩周湖、そして函館山の夜景（100万ドルの夜景）など、自然の造形美を紹介しています。

4.お問い合わせ。訪問者からの質問や感想を受け付けるフォームページです。

## 使用技術
フロントエンド: HTML5 / CSS / JavaScript

## サイトのセットアップ方法 (開発者向け)
このプロジェクトは静的なHTMLとCSSファイルで構成されているため、特別なサーバー設定は不要です。

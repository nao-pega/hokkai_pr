# hokkai_pr
🦌 北海道魅力発見!! (Hokkaido Charm Discovery!!)1. プロジェクト概要このプロジェクトは、日本最北の地である北海道の観光情報を集約し、そのグルメ、絶景スポット、文化・イベントの魅力を国内外に発信するシンプルなレスポンシブWebサイトです。北の大地をイメージした濃い青を基調とし、訪問者が北海道への旅に出たくなるような体験を提供します。

2. 主なコンテンツ・機能サイトは以下の主要な4ページで構成されています。ページ名ファイル名内容HOMEindex.html北海道の魅力を映し出すメインページです。スライドショー機能と、札幌雪まつり、YOSAKOIソーラン祭り、ライラックまつりなどの主要イベントの紹介を掲載しています。グルメ・特産品gurume.html北海道を代表する食文化を紹介するページです。札幌味噌ラーメン、新鮮なカニ・海鮮丼、ジンギスカン、銘菓（白い恋人など）、酪農製品（ソフトクリーム）といった名物を写真付きで解説しています。絶景スポットzekkei.html北海道各地の息をのむような美しい景色を特集したページです。美瑛の青い池、富良野のラベンダー畑、摩周湖、そして函館山の夜景（100万ドルの夜景）など、自然の造形美を紹介しています。お問い合わせtoiawase.html訪問者からの質問や感想を受け付けるフォームページです。

3. 使用技術フロントエンド: HTML5 / CSS3 / JavaScript (一部)スタイル:共通CSS (style.css) を使用し、デザインの一貫性を確保。モバイルフレンドリーなレスポンシブデザインに対応しています。ヘッダーのタイトルには、文字がアニメーションで跳ねるCSSアニメーションを採用しています。ナビゲーション: 全ページに共通のグローバルナビゲーションを設置。その他: ページトップへスムーズに戻るための**「トップへ戻る」ボタン**を実装。

4. サイトのセットアップ方法 (開発者向け)このプロジェクトは静的なHTMLとCSSファイルで構成されているため、特別なサーバー設定は不要です。このリポジトリのファイルを全てダウンロードまたはクローンします。各HTMLファイル (index.html, gurume.html, zekkei.html, toiawase.html) をWebブラウザで開きます。ファイル構成:.
├── index.html          # トップページ
├── gurume.html         # グルメ・特産品ページ
├── zekkei.html         # 絶景スポットページ
├── toiawase.html       # お問い合わせページ
├── css/
│   ├── style.css       # 共通CSSファイル
│   ├── gurume.css      # グルメページ用CSS
│   └── toiawase.css    # お問い合わせページ用CSS
└── static/
    └── img/            # 画像ファイル格納ディレクトリ
